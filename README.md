# UART-Verilog
# UART Transmitter and Receiver using Verilog HDL

## Description
Designed and simulated UART communication modules using Verilog HDL for serial data transmission.

## Features
- Baud rate generator
- FSM-based transmitter and receiver
- Serial communication
- Verilog testbench
- Simulation waveform verification

## Tools Used
- Verilog HDL
- Xilinx ISE
- Xilinx Simulator

## Project Files
- uart_tx.v
- uart_rx.v
- baud_generator.v
- uart_tb.v

## Applications
- FPGA communication
- Embedded systems
- Serial data transfer
